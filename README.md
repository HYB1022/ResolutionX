# ResolutionX

Lenovo Legion Y700용 게임 해상도 최적화 앱입니다.
게임을 할 때만 화면 해상도를 자동으로 낮추고, 게임에서 나가면 원래대로 되돌립니다.

Y700 4·5세대는 3K 디스플레이(3040×1904)를 씁니다. 안드로이드판 명조(Wuthering Waves)는 화면 해상도에 맞춰 렌더 해상도를 올리기 때문에 QHD보다 높은 해상도로 돌아가고, 그만큼 발열과 프레임 드랍이 생깁니다.
지금까지는 Pixels 같은 앱으로 게임 전에 해상도를 직접 낮추고, 끝나면 다시 되돌려야 했습니다. ResolutionX는 이 과정을 자동으로 처리합니다.

## 기능

- **화면 해상도 축소**: `wm size`와 `wm density`를 같은 비율로 낮춥니다. 레터박스 없이 전체 화면이 유지됩니다.
  - 권장값은 긴 변 2128px입니다. Y700 5세대에서는 70%, 즉 1332×2128 @ 308dpi입니다. 아래 실측 결과에서 120fps를 유지한 가장 높은 해상도입니다.
- **게임 진입·이탈 시 자동 전환**: 대상 게임이 화면에 뜨면 해상도를 낮추고, 다른 앱으로 나간 뒤 3초가 지나면 원래대로 되돌립니다.
  - 게임 위에 게임 도우미 같은 오버레이가 떠 있을 때는 해상도를 유지합니다.
- **홈 화면 바로가기**: 해상도를 먼저 낮춘 다음 게임을 실행합니다. 게임 실행 중에 해상도가 바뀌지 않아 가장 안정적인 방법입니다.
- **게임별 다운스케일 (선택)**: Android Game Mode(`cmd game set --downscale`)로 해당 게임의 렌더 해상도만 낮춥니다. Android 13 이상이 필요합니다.
- **복구 안전장치**: 시스템이 앱을 종료해도 셸에서 도는 감시 스크립트가 해상도를 되돌립니다. 강제 종료로 자동 전환 서비스가 해제되면 앱을 열 때 다시 켭니다.

## 요구 사항

- Android 11 이상. 실제로 확인한 기기는 Legion Y700 5세대(TB323FU, Android 16)입니다.
- [Shizuku](https://play.google.com/store/apps/details?id=moe.shizuku.privileged.api). 해상도 변경에 셸 권한이 필요합니다.

## 설치와 설정

1. [Releases](../../releases)에서 APK를 받아 설치합니다.
   - Play 프로텍트 경고가 뜨면 **검사**를 누르세요. 자세한 내용은 [문제 해결](#문제-해결)에 있습니다.
2. **Shizuku를 실행합니다.**
   - PC가 없을 때: Shizuku 앱에서 무선 디버깅으로 시작합니다. 개발자 옵션 → 무선 디버깅을 켜야 합니다.
   - PC가 있을 때: USB로 연결하고 Shizuku 앱에 나오는 `adb shell ...` 명령을 실행합니다.
3. ResolutionX를 열고 **권한 요청**을 누른 뒤 Shizuku 창에서 **허용**합니다.
4. **자동 전환 서비스 → 켜기**를 누릅니다. Shizuku로 바로 켜지기 때문에 사이드로드 앱에 걸리는 '제한된 설정'에 막히지 않습니다.
5. **게임 선택**에서 명조 등 대상 게임을 고릅니다.
6. 게임 줄의 **바로가기**를 눌러 홈 화면에 추가하고, 앞으로는 그 바로가기로 실행합니다.

## 실측 결과 (Y700 5세대, 명조)

같은 장소에 서 있는 상태에서 해상도만 바꿔 25초씩 측정했습니다. fps는 게임 도우미가 기록한 값입니다.

| 축소 비율 | 화면 해상도 | 렌더 해상도 | 평균 fps |
|---|---|---|---|
| 100% (기본) | 1904×3040 | 3040×1904 | 63.3 |
| 76% | 1448×2310 | 2304×1448 | 104.8 / 105.5 (두 번 측정) |
| **70% (권장)** | 1332×2128 | 2128×1328 | **119.3** |
| 68% | 1294×2068 | 2064×1288 | 119.2 |
| 65% | 1238×1976 | 1976×1232 | 119.2 |

- 이 장면에서는 GPU가 병목이라 해상도를 낮추면 fps가 크게 오릅니다. 70%부터 120fps 상한에 닿았습니다.
- 전투처럼 무거운 장면에서는 결과가 다를 수 있습니다. 그런 장면에서도 120fps를 유지하고 싶으면 65%까지 낮춰 보세요.
- 게임 도우미의 성능 모드를 켜도 게임 실행 중 CPU 클럭 제한(보조 코어 2.11GHz)은 그대로였습니다.

## 명조 추천 그래픽 설정

화면 해상도 축소를 쓸 때 기준입니다. 출처는 [아카라이브 명조 채널](https://arca.live/b/wutheringwaves/185934322)입니다.

| 항목 | 값 |
|---|---|
| 리소스 등급 | 고화질 |
| 그래픽 품질 미리 설정 | 최고 |
| 해상도 | 낮음 (필요하면 중간) |
| 프레임 | 45 + 프레임 보간 ON → 90fps. 발열을 감수하면 60 + 보간 → 120fps |
| 특수효과 / 그림자 | 중간 / 중간 |
| 그래픽 품질 | 매우 높음 |
| 식재 밀도 | 낮음 |
| 이방성 샘플 | 8× |
| 불칸 | ON |
| 기타 | 자동 조정만 빼고 모두 켜기 |

> 해상도를 낮추면 GPU 부담과 발열이 줄어듭니다. 하지만 도시처럼 CPU가 먼저 한계에 닿는 장면에서는 fps가 크게 오르지 않습니다.
> 120fps를 유지하고 싶다면 **60fps + 프레임 보간**을 쓰거나 게임 도우미의 **성능 모드**를 함께 켜는 것이 효과적입니다.

## 문제 해결

**설치할 때 Play 프로텍트가 '확인되지 않은 앱'이라며 검사하라고 해요**
- Play 스토어 밖에서 받은 앱이면 뜨는 정상적인 안내입니다. Google이 아직 모르는 앱이라는 뜻이고, 악성 앱이라는 뜻은 아닙니다.
- **검사**를 누르면 Google이 앱을 확인한 뒤 설치를 계속할 수 있습니다.
- 새 버전을 설치할 때 다시 뜰 수 있습니다. 버전마다 새 APK이기 때문입니다.
- 이 앱은 자동 전환에 접근성 서비스를 써서 더 엄격하게 검사될 수 있습니다. 접근성 서비스는 앱 전환과 패키지 이름만 봅니다([동작 방식](#동작-방식) 참고).
- 소스 코드는 이 저장소에 모두 공개되어 있습니다. 직접 확인하거나 [빌드](#빌드)해서 설치해도 됩니다.

**해상도가 낮은 채로 남았어요**
- 앱에서 **원래대로 복구**를 누릅니다.
- 앱을 쓸 수 없으면 PC에서 아래 명령을 실행합니다.
  ```
  adb shell wm size reset
  adb shell wm density reset
  ```
- 해상도 변경은 **재부팅 후에도 남습니다.** 게임 중에 재부팅했다면 Shizuku를 다시 시작한 뒤 앱에서 복구하세요.

**게임에 들어가도 해상도가 안 바뀌어요**
- 앱 상단에 `Shizuku: 연결됨 ✓`, `자동 전환 서비스: 켜짐 ✓`가 나오는지 확인합니다.
- 재부팅하면 Shizuku를 다시 시작해야 합니다.
- 시스템이 앱을 강제 종료하면 자동 전환 서비스가 해제됩니다. ResolutionX를 한 번 열거나 바로가기로 게임을 실행하면 다시 켜집니다.

**자동 전환 서비스를 끄고 싶어요**
- 앱의 **게임 진입 시 자동 적용** 스위치를 끕니다. 접근성 설정에서만 끄면 앱을 열 때 다시 켜질 수 있습니다.

## 동작 방식

| 구성 요소 | 역할 |
|---|---|
| `Shell` | Shizuku로 `sh -c` 명령을 실행합니다 |
| `Resolution` | 해상도와 DPI를 계산해 적용하고 복구합니다. Game Mode 다운스케일과 셸 감시 스크립트도 담당합니다 |
| `GameWatcherService` | 접근성 서비스입니다. 앱 전환(`TYPE_WINDOW_STATE_CHANGED`)을 감지해 해상도를 적용하거나 복구합니다 |
| `LaunchActivity` | 홈 화면 바로가기용입니다. 해상도를 적용한 뒤 게임을 실행합니다 |

접근성 서비스는 앱 전환 이벤트와 창의 패키지 이름만 봅니다. 화면 내용은 읽거나 저장하지 않습니다.

## 빌드

JDK 17과 Android SDK(platform 35)가 필요합니다.

```
./gradlew assembleRelease
# 출력: app/build/outputs/apk/release/app-release.apk
```

## 주의

- 시스템 해상도를 바꾸는 앱입니다. 문제가 생겨도 `wm size reset`으로 언제든 되돌릴 수 있습니다.
- 릴리스 APK는 개발용 키(debug keystore)로 서명되어 있습니다.
